# @tachui/eslint-plugin

ESLint plugin for TachUI projects, focused on migration safety and modifier-style consistency.

## Includes

- `@tachui/prefer-direct-modifiers` rule for moving from legacy `.modifier.*` chains to direct modifier calls.
- Autofix support for common migration patterns.

```bash
pnpm add -D @tachui/eslint-plugin eslint
```
