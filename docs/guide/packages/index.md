# Packages

tachUI ships as 17 focused packages so you can scale from the 16 KB runtime to the full desktop toolchain. Each package page contains installation steps, APIs, and migration notes.

> API references are contextual—use the package pages below (or their README copies) for TypeDoc links instead of a monolithic global API.

| Package | Summary | Status |
| --- | --- | --- |
| [`@tachui/core`](/packages/core/) | Reactive runtime, renderer, signals, lifecycle utilities | ✅ Stable |
| [`@tachui/primitives`](/packages/primitives/) | Building blocks (stacks, text, lists, imagery) | ✅ Stable |
| [`@tachui/modifiers`](/packages/modifiers/) | 130+ chainable modifiers for styling + interaction | ✅ Stable / expanding |
| [`@tachui/navigation`](/packages/navigation/) | Stacks, tabs, deep links (sheet/modal system in progress) | 🚧 |
| [`@tachui/forms`](/packages/forms/) | 27+ form components + validation utilities | ✅ Stable (hooks pending) |
| [`@tachui/grid`](/packages/grid/) | Grid layouts, responsive helpers | ✅ Stable |
| [`@tachui/data`](/packages/data/) | Lists, menus, data surfaces | ⚠️ Needs additional tests |
| [`@tachui/flow-control`](/packages/flow-control/) | Show/When/Unless/ForEach conditional helpers | ✅ Stable |
| [`@tachui/responsive`](/packages/responsive/) | Breakpoints, media queries, responsive debugging | ✅ Stable |
| [`@tachui/mobile`](/packages/mobile/) | ActionSheet, Alert, upcoming gestures | 🚧 |
| [`@tachui/viewport`](/packages/viewport/) | Multi-window / desktop scaffolding | ⚠️ Needs additional tests |
| [`@tachui/symbols`](/packages/symbols/) | Icon system + assets pipeline | ✅ Stable |
| [`@tachui/registry`](/packages/registry/) | Framework-wide registry/injection layer | ⚠️ Edge coverage in progress |
| [`@tachui/types`](/packages/types/) | Shared TypeScript contracts used across TachUI packages | ✅ Stable |
| [`@tachui/devtools`](/packages/devtools/) | Inspector, profiler, debugging helpers | ✅ Stable |
| [`@tachui/cli`](/packages/cli/) | Project scaffolding, codemods, optimizers | 🚧 |
| [`@tachui/eslint-plugin`](/packages/eslint-plugin/) | Lint rules for TachUI migration and modifier style consistency | ✅ Stable |

Use the sidebar to jump directly into each package.
