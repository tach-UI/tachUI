# @tachui/registry

Framework-wide registry and injection layer used by TachUI packages for shared component/modifier/service wiring.

## Responsibilities

- Register and resolve framework services.
- Coordinate modifier registration across package boundaries.
- Provide consistent dependency lookup for runtime modules.

```bash
pnpm add @tachui/registry
```

[View README on GitHub](https://github.com/tach-ui/tachUI/tree/main/packages/registry/README.md)
