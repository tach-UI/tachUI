# @tachui/types

Shared TypeScript contracts for the TachUI ecosystem. This package centralizes runtime, modifier, reactive, and layout type definitions used across workspace packages.

## Highlights

- Shared interfaces like `ComponentInstance`, `DOMNode`, and `Signal`.
- Modifier contracts (`Modifier`, `ModifierContext`, priorities, metadata).
- Type-only package design to keep runtime bundles lean.

```bash
pnpm add -D @tachui/types
```
